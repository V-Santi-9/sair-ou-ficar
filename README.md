# Sair ou Ficar

Estudo sobre empresários e pessoas que deixam o Brasil (Paraguai, Portugal, EUA, Uruguai, Emirados, Espanha, Itália):
normas, casos, relatos, simulador e diagnóstico por eixos.

Site: https://v-santi-9.github.io/sair-ou-ficar/

Atualizado diariamente por uma rotina automática (veja `tools/ROTINA.md`); o histórico de mudanças fica em `atualizacoes/`.
Conteúdo informativo. Não constitui consultoria tributária, jurídica ou de investimentos.
